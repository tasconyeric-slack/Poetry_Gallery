# 写诗、导入与微信分享 MVP（Task B）

前端保留现有原生 JavaScript、浏览器本机草稿及 Worker 直连路线，无新增运行依赖。

## 使用体验

- 写诗、即时预览、刷新恢复；本机、正在保存、云端、发布、失败及离线状态分别显示。清除浏览器数据仍会丢失本机草稿，请导出备份。
- 以 TXT / Markdown（UTF-8，256 KB 内）或粘贴导入，正文最多 30000 字。仅识别 Markdown 标题，或“短首行 + 空行”的简单标题；无法确定时将全部文字作为正文供用户确认。导入建立新本机草稿，不自动上传。暂不支持 DOCX。
- 保存到云端保留当前发布状态；撤回为独立确认操作。删除需要确认。历史恢复要求先保存当前修改。云端重读先将未同步文字另存本机副本。
- 保存、上传、删除期间锁定编辑与切换；图片选择不再触发正文变脏。上传后刷新作品卡片闭包，重开可以读取配图；异步配图返回核对编辑会话，避免串图。
- 作者密钥仅页面内存使用，配置收进折叠区；前台视频入口隐藏，视频模块和测试保留。CI 核心浏览器验收改跑写作分享路径，不再从隐藏入口启动视频。

## 分享与公开读取

保留稳定的 `/#poem/UUID` 链接，独立打开与刷新都通过公开 detail API 重新读取；列表缓存不能绕过撤回。返回页面时重新核验。已经被接收者复制或保存的内容无法撤销。

原生 Web Share 可用时调用系统分享，用户取消只显示取消；不可用或调用失败时复制链接，再降级到可手动选择的输入框。另有独立复制按钮。这不等于接入微信 JS-SDK，也不保证出现微信定制分享菜单。

PNG 在浏览器本机生成，无第三方上传。竖版最多 34 个换行后的排版行，方形最多 9 行；超出或标题署名过长时明确提示使用原文链接或打印 PDF，隐藏旧诗卡避免误用。移动端正文可选择复制，取消浮动导航遮挡。

## 与 Session A 的接口要求

- 保持现有 `PUBLIC_API` Worker 地址与 op 参数；所有私有读取和写操作使用内存作者密钥。
- `save` 使用现有 `localId` UUID 作为新建幂等标识，返回 `{id,version}`；409 时保留本机修改，用户可重读云端并找回本机副本。
- `upload` 请求 `{poem_id,version,mime,base64}`，返回 `{cover_id,version}`，递增版本并记录历史。正文未同步时前端要求先保存，避免用过期版本上传。失败不得改正文。
- `delete` 请求 `{id,version,confirm:true}`；服务端核验版本。`restore` 恢复历史正文及 cover_id；前端重读作者列表获取完整恢复结果。
- 未发布 / 撤回作品公开 detail 与 cover 必须拒绝读取；公开资源不可使用长期缓存绕过撤回。本文仅前端提交，不修改 Worker、API、迁移或部署配置。
- 正文仅以 trim 判断非空，保存原始换行与首尾空行；Session A 已确认实现。

Hash 不发送给服务器，目前微信抓取仍只能得到站点通用预览。最小后续方案由 A 提供 `/p/UUID` 的轻量 HTML 响应，先验证作品已发布，再输出转义后的标题、摘要、公开封面 OG 元数据及原文阅读入口；撤回返回不可读取且不长期缓存。B 本轮不改变路由、不增加框架，专属 OG 不阻塞真实链接分享。
